# HU05 — ROI Proyectado de Flota Electrica

## Descripcion

Esta funcionalidad permite estimar el Retorno de Inversion (ROI) al reemplazar autobuses diesel por modelos electricos en una ruta especifica. Compara los costos anuales de operacion (energia electrica vs diesel + ahorros en mantenimiento) contra la inversion inicial para calcular el periodo de recuperacion y porcentaje de ROI. Incluye tambien catalogos de modelos de autobus y rutas con distancia calculada a partir de datos GTFS.

---

## Endpoints

### GET /api/roi/estimate

Calcula la proyeccion de ROI para una ruta y modelo electrico especificos.

**Parametros de query:**

| Parametro | Tipo   | Requerido | Default | Validacion                |
|-----------|--------|-----------|---------|---------------------------|
| routeId   | String | Si        | —       | No nulo, no vacio         |
| modelId   | Long   | Si        | —       | No nulo                   |
| buses     | int    | No        | 10      | >= 1                      |

**Respuesta 200 OK:**

```json
{
  "roiPercent": 4.808,
  "paybackYears": 20.8,
  "netAnnualReturn": 353400.0,
  "totalInvestmentMXN": 7350000.0,
  "co2AvoidedTons": 58.28,
  "electricCostPerYear": 173600.0,
  "dieselCostPerYear": 520800.0
}
```

**Errores:**

| Codigo | Condicion                              | Mensaje                                  |
|--------|----------------------------------------|------------------------------------------|
| 400    | routeId nulo o vacio                   | El parametro routeId es requerido        |
| 400    | modelId nulo                           | El parametro modelId es requerido        |
| 400    | buses < 1                              | El numero de buses debe ser al menos 1   |
| 400    | Modelo seleccionado es DIESEL          | El modelo seleccionado no es electrico   |
| 404    | Ruta no encontrada                     | Ruta no encontrada: {routeId}            |
| 404    | Modelo no encontrado                   | Modelo de bus no encontrado: {modelId}   |
| 500    | Error inesperado                       | Error inesperado                         |

## Logica de Negocio

### Formulas de calculo

Todas las formulas viven en `FleetCalculator.java` como funciones puras:

| Calculo               | Formula                                                              |
|-----------------------|----------------------------------------------------------------------|
| kmPerBusPerYear       | `distanceKm x DAILY_TRIPS x OPERATING_DAYS`                         |
| totalInvestmentMXN    | `buses x unitCostUsd x MXN_PER_USD`                                 |
| electricCostPerYear   | `buses x kmPerYear x energyConsumptionKwhKm x PRICE_PER_KWH_MXN`    |
| dieselCostPerYear     | `buses x kmPerYear x fuelConsumptionLKm x DIESEL_PRICE_PER_LITER_MXN` |
| maintenanceSavings    | `buses x kmPerYear x (dieselMaintPerKm - electricMaintPerKm)`        |
| netAnnualReturn       | `dieselCostPerYear - electricCostPerYear + maintenanceSavings`        |
| roiPercent            | `(netAnnualReturn / totalInvestmentMXN) x 100`                       |
| paybackYears          | `totalInvestmentMXN / netAnnualReturn`                                |
| co2AvoidedTons        | `(buses x kmPerYear x co2EmissionsGKm) / 1,000,000`                  |

### Linea base diesel

Se usa el primer modelo DIESEL de la base de datos (ordenado por ID) como referencia para comparar costos. Actualmente: ID 4 = Yutong DMT Hybrid H8.

### Rechazo de modelo diesel

Si el `modelId` seleccionado es DIESEL, el endpoint retorna 400 porque la comparacion de ROI solo aplica para un modelo electrico contra la linea base diesel.

## Constantes (FleetConstants.java)

| Constante                    | Valor | Unidad  |
|------------------------------|-------|---------|
| DAILY_TRIPS                  | 10    | viajes  |
| OPERATING_DAYS               | 310   | dias    |
| MXN_PER_USD                  | 17.5  | MXN/USD |
| PRICE_PER_KWH_MXN            | 2.8   | MXN/kWh |
| DIESEL_PRICE_PER_LITER_MXN   | 24.0  | MXN/L   |
