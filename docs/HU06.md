# HU06 — Visualizar Ahorro Acumulado en Combustible por Escenario

## Descripcion

Esta funcionalidad permite al Director General (CEO) visualizar el ahorro acumulado en combustible al reemplazar la flota diesel por autobuses electricos en un escenario especifico (ruta + modelo electrico + cantidad de buses). El calculo expresa el ahorro tanto en pesos mexicanos como en litros de diesel evitados, considerando el precio de referencia del diesel y el consumo estimado de la flota actual. Los datos pueden visualizarse por periodo (mensual, anual, acumulado) y exportarse en formato CSV o PDF.

---

## Endpoints

### GET /api/fuel-savings

Calcula el ahorro en combustible para un escenario de flota electrica.

**Parametros de query:**

| Parametro | Tipo   | Requerido | Default | Validacion                |
|-----------|--------|-----------|---------|---------------------------|
| routeId   | String | Si        | —       | No nulo, no vacio         |
| modelId   | Long   | Si        | —       | No nulo                   |
| buses     | int    | No        | 10      | >= 1                      |
| years     | int    | No        | 5       | >= 1 y <= 10              |

**Respuesta 200 OK:**

```json
{
  "routeId": "TR13",
  "routeDistanceKm": 20.0,
  "busModelId": 1,
  "busModelName": "Yutong E12PRO",
  "numberOfBuses": 10,
  "fuelSavingsMXN": 3472000.0,
  "fuelSavingsLiters": 217000.0,
  "dieselReferencePriceMXN": 24.0,
  "dieselConsumptionLKm": 0.35,
  "dieselCostPerYear": 5208000.0,
  "electricCostPerYear": 1736000.0,
  "projectionYears": 5
}
```

**Errores:**

| Codigo | Condicion                              | Mensaje                                            |
|--------|----------------------------------------|----------------------------------------------------|
| 400    | routeId nulo o vacio                   | El parametro routeId es requerido                  |
| 400    | modelId nulo                           | El parametro modelId es requerido                  |
| 400    | buses < 1                              | El numero de buses debe ser al menos 1             |
| 400    | years < 1 o years > 10                | El periodo de proyeccion debe ser entre 1 y 10 anos|
| 400    | Modelo seleccionado es DIESEL          | El modelo seleccionado debe ser electrico          |
| 404    | Ruta no encontrada                     | Ruta no encontrada: {routeId}                      |
| 404    | Modelo no encontrado                   | Modelo de bus no encontrado: {modelId}             |
| 500    | Error inesperado                       | Error inesperado                                   |

## Logica de Negocio

### Formulas de calculo

Todas las formulas viven en `FleetCalculator.java` como funciones puras:

| Calculo               | Formula                                                                |
|-----------------------|------------------------------------------------------------------------|
| kmPerBusPerYear       | `distanceKm x DAILY_TRIPS x OPERATING_DAYS`                           |
| dieselCostPerYear     | `buses x kmPerYear x fuelConsumptionLKm x DIESEL_PRICE_PER_LITER_MXN` |
| electricCostPerYear   | `buses x kmPerYear x energyConsumptionKwhKm x PRICE_PER_KWH_MXN`      |
| fuelSavingsMXN        | `dieselCostPerYear - electricCostPerYear`                              |
| fuelSavingsLiters     | `buses x kmPerYear x fuelConsumptionLKm` (diesel liters avoided)      |

### Derivaciones en frontend (no calculadas en backend)

| Vista       | Derivacion                                      |
|-------------|------------------------------------------------|
| Mensual     | `fuelSavingsMXN / 12` y `fuelSavingsLiters / 12` por mes |
| Anual       | `fuelSavingsMXN x year` por ano (1 a projectionYears)    |
| Acumulado   | Suma acumulada: ano N = `fuelSavingsMXN x N`             |

### Linea base diesel

Se usa el primer modelo DIESEL de la base de datos (ordenado por ID) como referencia. Actualmente: Yutong ZK6128HGD (fuelConsumptionLKm = 0.35).

### Constantes aplicadas

| Constante                    | Valor | Unidad  |
|------------------------------|-------|---------|
| DAILY_TRIPS                  | 10    | viajes  |
| OPERATING_DAYS               | 310   | dias    |
| DIESEL_PRICE_PER_LITER_MXN   | 24.0  | MXN/L   |
| PRICE_PER_KWH_MXN            | 2.8   | MXN/kWh |
