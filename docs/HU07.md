# HU07 — Reduccion de Emisiones CO2

## Descripcion

Esta funcionalidad agrega metricas KPI a nivel de flota completa, combinando todas las rutas con todos los modelos electricos disponibles. Muestra el ahorro total en combustible, las toneladas de CO2 evitadas, la inversion requerida y el desglose de costos electrico vs diesel. Orientado a dashboards ejecutivos para la toma de decisiones sobre la transicion de flota.

---

## Endpoints

### GET /api/kpi/summary

Calcula metricas KPI agregadas para toda la flota.

**Parametros de query:**

| Parametro     | Tipo | Requerido | Default | Validacion |
|---------------|------|-----------|---------|------------|
| busesPerRoute | int  | No        | 10      | >= 1       |

**Respuesta 200 OK:**

```json
{
  "totalFuelSavingsMXN": 1250000.0,
  "totalCo2AvoidedTons": 185.5,
  "totalInvestmentMXN": 22050000.0,
  "totalElectricCostMXN": 520800.0,
  "totalDieselCostMXN": 1562400.0,
  "routesAnalyzed": 2
}
```

**Errores:**

| Codigo | Condicion                | Mensaje                           |
|--------|--------------------------|-----------------------------------|
| 400    | busesPerRoute < 1        | busesPerRoute debe ser al menos 1 |
| 500    | Error inesperado         | Error inesperado                  |

## Logica de Negocio

### Estrategia de agregacion

El use case `GetKpiMetricsUseCase` ejecuta un doble ciclo:

1. Obtiene todas las rutas con distancia valida
2. Obtiene todos los modelos electricos y el primer modelo diesel como linea base
3. Para cada ruta, para cada modelo electrico:
   - Calcula `kmPerBusPerYear` usando la distancia de la ruta
   - Calcula costos electricos y diesel anuales
   - Calcula ahorro en combustible y CO2 evitado
   - Calcula la inversion requerida
4. Acumula todos los totales

### Formulas

Usa las mismas funciones puras de `FleetCalculator.java` que HU05:

| Calculo                | Formula                                                              |
|------------------------|----------------------------------------------------------------------|
| kmPerBusPerYear        | `distanceKm x DAILY_TRIPS x OPERATING_DAYS`                         |
| totalInvestmentMXN     | `buses x unitCostUsd x MXN_PER_USD`                                 |
| electricCostPerYear    | `buses x kmPerYear x energyConsumptionKwhKm x PRICE_PER_KWH_MXN`    |
| dieselCostPerYear      | `buses x kmPerYear x fuelConsumptionLKm x DIESEL_PRICE_PER_LITER_MXN` |
| totalFuelSavingsMXN    | `sum(dieselCost) - sum(electricCost)` en todas las combinaciones     |
| totalCo2AvoidedTons    | `sum(co2AvoidedTons)` en todas las combinaciones                     |
| routesAnalyzed         | Cantidad de rutas con distancia valida                               |

### Linea base diesel

Igual que HU05: se usa el primer modelo DIESEL de la base de datos (ordenado por ID) como referencia para todas las comparaciones de costo.

## Relacion con HU05

| Aspecto      | HU05                         | HU07                              |
