# HU08 — Consultar especificaciones técnicas de modelos de autobús

## Descripcion

El Director General (CEO) puede consultar las especificaciones técnicas y financieras de los modelos de autobús registrados en el catálogo. La vista es de solo lectura — no requiere edición de datos.

## Endpoints

### GET /api/bus-models

Retorna todos los modelos de autobús del catálogo, ordenados por `id`.

**Autenticación:** No requerida (endpoint público).

**Respuesta exitosa (200):**

```json
[
  {
    "id": 1,
    "name": "Yutong E12PRO",
    "manufacturer": "Yutong",
    "fuelType": "ELECTRIC",
    "autonomyKm": 300.00,
    "passengerCapacity": 85,
    "unitCostUsd": 420000.00,
    "batteryCapacityKwh": 352.08,
    "energyConsumptionKwhKm": 1.0000,
    "fuelConsumptionLKm": 0.0000,
    "maintenanceCostPerKm": 0.1200,
    "co2EmissionsGKm": 0.00
  }
]
```

### GET /api/bus-models/{id}

Retorna un modelo de autobús por su ID.

**Autenticación:** No requerida.

**Respuesta exitosa (200):** Mismo esquema que un elemento del array anterior.

**Error (404):**

```
Modelo de bus no encontrado
```

## Campos del modelo

| Campo | Tipo | Descripción |
|-------|------|-------------|
| `id` | Long | Identificador único |
| `name` | String | Nombre del modelo |
| `manufacturer` | String | Fabricante |
| `fuelType` | Enum | `ELECTRIC` o `DIESEL` |
| `autonomyKm` | BigDecimal | Autonomía en kilómetros |
| `passengerCapacity` | Integer | Capacidad de pasajeros |
| `unitCostUsd` | BigDecimal | Costo unitario en USD |
| `batteryCapacityKwh` | BigDecimal | Capacidad de batería (kWh) |
| `energyConsumptionKwhKm` | BigDecimal | Consumo energético (kWh/km) |
| `fuelConsumptionLKm` | BigDecimal | Consumo de combustible (L/km) |
| `maintenanceCostPerKm` | BigDecimal | Costo de mantenimiento por km |
| `co2EmissionsGKm` | BigDecimal | Emisiones CO2 (g/km) |

## Lógica de negocio

No hay lógica de negocio adicional. Los endpoints exponen directamente los datos del catálogo almacenados en la tabla `bus_models`. No se requiere un use case — el resource llama al repository directamente.

## Arquitectura

```
BusModelResource (interfaces/rest)
    └── BusModelRepository (domain/repository)
            └── BusModelRepositoryImpl (infrastructure/repository)
                    └── BusModelEntity (infrastructure/entities)
                            └── bus_models (MySQL table)
```

- **Resource:** Recibe petición HTTP, llama al repository, retorna Response.
- **Repository:** Interface en domain, implementación en infrastructure con EntityManager.
- **Mapper:** `BusModelMapper` convierte entre `BusModelEntity` y `BusModel` (domain).

## Criterios de aceptación

- AC1: El sistema muestra las especificaciones técnicas y financieras de cada modelo.
- AC2: La vista incluye al menos autonomía, capacidad de pasajeros y costo unitario.
- AC3: El Director General puede acceder sin necesidad de editar.
