# HU13 — Agregar modelo de autobús al catálogo

## Descripcion

El Administrador puede agregar un nuevo modelo de autobús al catálogo para mantener actualizadas las opciones disponibles. Cada modelo incluye nombre, fabricante, tipo de combustible, autonomía, capacidad de pasajeros, costo unitario y campos técnicos opcionales. Los cambios se reflejan de inmediato en todas las vistas del sistema.

## Endpoints

### POST /api/bus-models

Crea un nuevo modelo de autobús en el catálogo.

**Autenticación:** No requerida.

**Body (JSON):**

```json
{
  "name": "BYD K9M",
  "manufacturer": "BYD",
  "fuelType": "ELECTRIC",
  "autonomyKm": 250.00,
  "passengerCapacity": 75,
  "unitCostUsd": 380000.00,
  "batteryCapacityKwh": 324.00,
  "energyConsumptionKwhKm": 1.20,
  "fuelConsumptionLKm": 0.00,
  "maintenanceCostPerKm": 0.10,
  "co2EmissionsGKm": 0.00
}
```

**Respuesta exitosa (201):**

```json
{
  "message": "Modelo agregado correctamente",
  "model": {
    "id": 7,
    "name": "BYD K9M",
    "manufacturer": "BYD",
    "fuelType": "ELECTRIC",
    "autonomyKm": 250.00,
    "passengerCapacity": 75,
    "unitCostUsd": 380000.00,
    "batteryCapacityKwh": 324.00,
    "energyConsumptionKwhKm": 1.2000,
    "fuelConsumptionLKm": 0.0000,
    "maintenanceCostPerKm": 0.1000,
    "co2EmissionsGKm": 0.00
  }
}
```

**Errores:**

| Codigo | Condicion                             | Mensaje                                 |
|--------|---------------------------------------|-----------------------------------------|
| 409    | Ya existe un modelo con ese nombre    | Ya existe un modelo con ese nombre      |
| 400    | `fuelType` no es `ELECTRIC` o `DIESEL`| Tipo de combustible inválido            |
| 500    | Error inesperado del servidor         | Error inesperado                        |

## Campos del modelo

| Campo | Tipo | Requerido | Descripcion |
|-------|------|-----------|-------------|
| `name` | String | Si | Nombre del modelo (único) |
| `manufacturer` | String | Si | Fabricante |
| `fuelType` | Enum | Si | `ELECTRIC` o `DIESEL` |
| `autonomyKm` | BigDecimal | Si | Autonomía en kilómetros |
| `passengerCapacity` | Integer | Si | Capacidad de pasajeros |
| `unitCostUsd` | BigDecimal | Si | Costo unitario en USD |
| `batteryCapacityKwh` | BigDecimal | No | Capacidad de batería (kWh), default 0 |
| `energyConsumptionKwhKm` | BigDecimal | No | Consumo energético (kWh/km), default 0 |
| `fuelConsumptionLKm` | BigDecimal | No | Consumo de combustible (L/km), default 0 |
| `maintenanceCostPerKm` | BigDecimal | No | Costo de mantenimiento por km, default 0 |
| `co2EmissionsGKm` | BigDecimal | No | Emisiones CO2 (g/km), default 0 |

## Logica de Negocio

1. Se verifica que no exista un modelo con el mismo `name` (unicidad) antes de persistir.
2. Los campos técnicos opcionales (`batteryCapacityKwh`, `energyConsumptionKwhKm`, `fuelConsumptionLKm`, `maintenanceCostPerKm`, `co2EmissionsGKm`) se establecen en `0` si no se envían.
3. El `fuelType` se convierte a mayúsculas antes de la validación del enum.
4. Se persiste con `created_at` y `updated_at` con la fecha y hora actual.

## Arquitectura

```
POST /api/bus-models
    └── BusModelResource (interfaces/rest)
            └── CreateBusModelUseCase (application/usecase)
                    └── BusModelRepository.findByName() — verificar unicidad
                    └── BusModelRepository.create()     — persistir
                            └── BusModelRepositoryImpl (infrastructure/repository)
                                    └── BusModelMapper.toEntity()
                                    └── EntityManager.persist()
                                    └── BusModelMapper.toDomain()
```

## Criterios de aceptacion

- AC1: El administrador puede agregar un registro al catálogo con todos sus campos.
- AC2: Cada modelo incluye al menos nombre, capacidad, autonomía y costo.
- AC3: Los cambios en el catálogo se reflejan de inmediato en las vistas del CEO (GET /api/bus-models).
