# HU15 — Eliminar modelo de autobús del catálogo

## Descripcion

El Administrador puede eliminar un modelo de autobús del catálogo para retirar opciones que ya no son vigentes. El modelo eliminado deja de aparecer de forma inmediata en todas las vistas del sistema.

## Endpoints

### DELETE /api/bus-models/{id}

Elimina permanentemente un modelo de autobús del catálogo.

**Autenticación:** No requerida.

**Path param:** `id` — Long, identificador del modelo.

**Respuesta exitosa (200):**

```json
{
  "message": "Modelo eliminado correctamente"
}
```

**Errores:**

| Codigo | Condicion                          | Mensaje                          |
|--------|------------------------------------|----------------------------------|
| 404    | No existe un modelo con ese `id`   | Modelo de bus no encontrado      |
| 500    | Error inesperado del servidor      | Error inesperado                 |

## Logica de Negocio

1. Se verifica que el modelo exista por `id`. Si no existe se lanza `BusModelNotFoundException` → 404.
2. Se elimina la entidad de la base de datos de forma permanente (`EntityManager.remove()`).
3. Tras la eliminación el modelo no aparece en `GET /api/bus-models` ni en `GET /api/bus-models/{id}` (404).

## Arquitectura

```
DELETE /api/bus-models/{id}
    └── BusModelResource (interfaces/rest)
            └── DeleteBusModelUseCase (application/usecase)
                    └── BusModelRepository.findById()   — verificar existencia
                    └── BusModelRepository.deleteById() — eliminar
                            └── BusModelRepositoryImpl (infrastructure/repository)
                                    └── EntityManager.find()
                                    └── EntityManager.remove()
```

## Criterios de aceptacion

- AC1: El administrador puede eliminar un modelo del catálogo.
- AC2: El sistema solicita confirmación antes de ejecutar la eliminación (responsabilidad del frontend).
- AC3: El modelo eliminado deja de aparecer en todas las vistas del sistema de forma inmediata.
