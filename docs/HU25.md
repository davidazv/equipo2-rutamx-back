# HU25 – Descargar lista de usuarios en CSV

## Descripción
Como Administrador quiero descargar la lista de usuarios en CSV para tener un respaldo o compartir la información con otros sistemas.

## Criterios de Aceptación
- **AC1:** El sistema genera y descarga un archivo CSV con la lista de usuarios registrados.
- **AC2:** El archivo incluye nombre completo, correo y rol de cada usuario.
- **AC3:** La descarga requiere autenticación como administrador.

## Implementación

### Backend

| Capa | Archivo | Descripción |
|---|---|---|
| Use case | `application/usecase/ExportUsersUseCase.java` | Obtiene todos los usuarios y genera el CSV con encabezado `nombre,correo,rol`. Escapa comas y comillas dobles según RFC 4180. |
| Resource | `interfaces/rest/UserResource.java` | `GET /admin/users/export` — devuelve `text/csv` con `Content-Disposition: attachment; filename="usuarios_YYYY-MM-DD.csv"`. Requiere `authContext` con rol ADMIN. |
| Auth | `infrastructure/security/FirebaseAuthFilter.java` | `/admin/users/export` excluido del bloque público de `/admin/users`, fuerza autenticación ADMIN. |

### Frontend

| Archivo | Cambio |
|---|---|
| `src/lib/api/users.ts` | Nueva función `exportUsersCsv()` — llama al endpoint con token Bearer, lee el nombre de archivo del header `Content-Disposition` y dispara la descarga via `<a download>`. |
| `src/app/admin/users/page.tsx` | Botón "Exportar CSV" conectado a `handleExportCsv()` con estado `exporting` para deshabilitar el botón durante la descarga y mostrar toast de éxito/error. |

## Endpoint

```
GET /admin/users/export
Authorization: Bearer <firebase-token>

Response 200:
Content-Type: text/csv
Content-Disposition: attachment; filename="usuarios_2026-05-22.csv"

nombre,correo,rol
Admin RutaMX,admin@rutamx.com,ADMIN
...
```

## Tests

- `ExportUsersUseCaseTest` (unit, 4 casos): encabezado CSV, fila de usuario, escape de comas, múltiples usuarios.
- `UserResourceTest` (integración, +4 casos): status 200, Content-Type `text/csv`, encabezado CSV en body, header `Content-Disposition` con `attachment` y prefijo `usuarios_`.
